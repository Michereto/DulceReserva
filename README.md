# DulceReserva
Descripción: aplicación web para gestionar encargos de una pastelería y mejorar la coordinación entre tienda y obrador.
Funcionalidades: encargos, catálogo, permisos, disponibilidad, estados y previsiones.
Tecnologías: HTML, CSS, JavaScript, Bootstrap 5, PHP, MySQL/MariaDB, XAMPP y Git.
Estado: Fase 3, planificación de la ejecución.
Autor: Miguel Ángel Moya González.
