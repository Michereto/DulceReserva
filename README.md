# DulceReserva

## Descripción del proyecto
DulceReserva es una aplicación web destinada a gestionar los encargos de una pastelería y mejorar la comunicación entre el personal de tienda y el obrador.

El proyecto surge de una necesidad real: actualmente los encargos se anotan en papel, lo que dificulta su organización, búsqueda y control, especialmente durante campañas de gran volumen de trabajo, como Navidad.

## Objetivo
Desarrollar una aplicación que permita centralizar los encargos en una base de datos, consultar su estado y organizar la producción según las fechas y horas de recogida.

## Usuarios de la aplicación

### Personal de tienda
- Registrar nuevos encargos.
- Consultar y buscar pedidos.
- Modificar o cancelar encargos.
- Gestionar el catálogo de productos y variedades.
- Marcar los encargos como recogidos.

### Personal del obrador
- Consultar los encargos registrados.
- Marcar pedidos como preparados.
- Consultar previsiones de producción por fecha, hora, producto y variedad.
- Consultar la carga de trabajo prevista.

## Funcionalidades previstas
- Inicio de sesión con permisos diferenciados según el usuario.
- Gestión de encargos y datos de clientes.
- Catálogo de productos y variedades activos o inactivos.
- Consulta de disponibilidad antes de registrar un encargo.
- Avisos cuando se superen los límites de capacidad configurados.
- Búsquedas y filtros por fecha, hora, producto y estado.
- Estados de encargos: pendiente, preparado, recogido y cancelado.
- Previsiones diarias y por horas para el obrador.
