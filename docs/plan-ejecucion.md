# Plan de ejecución de DulceReserva

## Objetivo
Desarrollar una aplicación web para gestionar los encargos de una pastelería y mejorar la coordinación entre tienda y obrador.

## Periodo de desarrollo
- Inicio previsto: 16 de noviembre de 2026.
- Finalización prevista: 16 de mayo de 2027.
- Dedicación estimada: 153 horas.
- Número de tareas: 24.

## Organización del trabajo
1. Preparación del entorno y diseño.
2. Creación de la base de datos.
3. Desarrollo de usuarios y catálogo.
4. Registro y gestión de encargos.
5. Consulta de disponibilidad y capacidad.
6. Previsiones de producción del obrador.
7. Integración y pruebas.
8. Despliegue y documentación.

## Herramientas
Visual Studio Code, XAMPP, PHP, MySQL/MariaDB, Bootstrap 5, Git y GitHub.

## Seguimiento
Se utilizarán GitHub Issues para registrar tareas e incidencias. El progreso se revisará semanalmente.

## Control de versiones
Se realizarán commits al finalizar las sesiones con cambios relevantes. La rama main contendrá las versiones estables.

## Copias de seguridad
El código se sincronizará con GitHub y se realizarán exportaciones periódicas de la base de datos.

## Documentación
La planificación completa, las dependencias y el Gantt se recogen en el documento académico de la Fase 3.
